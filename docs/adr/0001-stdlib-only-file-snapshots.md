# ADR-0001: Только stdlib и файловые снапшоты как контракт

## Status
proposed

## Context
ТЗ v0.5 (NFR-1, утверждено владельцем) требует портативности: скилл должен запускаться одинаково из Hermes, Claude Code и вручную, без установки пакетов. Скрипты обмениваются данными через файлы `data/*.json`; эти файлы — единственный контракт между `fetch_*` и `query.py`. Репозиторий-скилл совмещён с governance-файлами проекта.

## Options considered
1. Чистый Python 3.10+, только stdlib; JSON-файлы в `data/` (по ТЗ).
2. Python с зависимостями (`requests`, `pandas`, `pyarrow`); те же JSON-файлы.
3. Локальная база SQLite вместо JSON (stdlib, но не читается глазами и плохо диффится).

## Decision
Вариант 1 предложен как формализация уже утверждённого ТЗ. Статус `proposed` до подтверждения владельцем на Gate 1.

## Consequences
### Positive
- Нулевая установка, одинаковый запуск везде.
- Снапшоты читаются и диффятся в Git; их легко подменять фикстурами в тестах.

### Negative
- LMArena читается через JSON-API Hugging Face, без parquet: объём и полнота зависят от этого API.
- Нет pandas: статистика (медиана, min-max) пишется вручную.
- Схема снапшотов — публичный контракт: её изменение требует новой версии схемы и миграции.
